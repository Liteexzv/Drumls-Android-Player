DRUMLS — оффлайн-плеер для Android

КАК ПОЛУЧИТЬ APK (вариант 1, без компьютерных навыков — GitHub):
1. Зарегистрируйся на github.com, создай новый репозиторий.
2. Нажми "uploading an existing file" и перетащи ВСЕ файлы из этой папки (вместе с папкой .github).
3. Открой вкладку Actions -> "Build APK" -> дождись зелёной галочки (~3-5 мин).
4. Внизу страницы скачай "Drumls-apk" -> внутри app-debug.apk.
5. Скинь APK на телефон и установи (разреши "Установку из неизвестных источников").

ВАРИАНТ 2 — Android Studio:
File -> Open -> выбери эту папку -> Build -> Build APK(s).

ВАРИАНТ 3 — без сборки:
Открой index.html в Chrome на телефоне -> меню -> "Добавить на главный экран".
